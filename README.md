## 📌 Executive Summary
This repository contains the end-to-end quantitative analytics engine, interactive war-room dashboard, and comprehensive auction strategy report built for **Rajasthan Royals' SupeRR Selector Season 2 (Round 1: Identify the Most Reliable Players Under Pressure)**.

Analyzing **200,999 deliveries across 883 matches (2022–2026)**, we developed two proprietary sabermetric indices:
1. **Batting Pressure Performance Index (PPI)**: Phase-weighted evaluation emphasizing Death Overs (16–20) Strike Rate (30%), High-RRR Chases (25%), Dot Ball Minimization (20%), Boundary Frequency (15%), and Baseline Delta (10%).
2. **Bowling Pressure Performance Index (B-PPI)**: Defensive reliability scoring emphasizing Death Economy (35%), Dot Ball % (25%), High-RRR Suppression (20%), Powerplay Economy (10%), and Pressure Wicket Frequency (10%).
